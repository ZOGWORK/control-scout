Scout, rebuilt for the stands

Pick the event once, then scout match by match, with every team you're watching in one place. The phone is clickable: tap counters, switch teams, save a match and see it move to the next one. Use the steps to jump between screens.

What this fixes from today's page

  • No more typing the event and match. The event is set once and stays. Matches come from the schedule.
  • A whole match in one go. One team, one alliance or all four, each as a tab, with one Save.
  • Save goes to the next match. Today Save closes the form and you start again from blank.
  • One phase at a time. Big tap targets for counters, and ratings moved to "After".
  • Six toolbar buttons move to Data. Pick list, Activity, Assignments, Export, Recordings and Template stay, just out of the way.
  • You can see what you missed. The match strip shows done, skipped and next.
